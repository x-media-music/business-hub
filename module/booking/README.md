# Booking-Modul

Der komplette Buchungs-Workflow steht in `.claude/rules/01_booking.md`:
Anfrage → Angebot → Vertrag → Technik/Rider → Kalender (RES/TBA/TBC,
Doppelbuchungs-Schutz) → Event-Vorbereitung (Info Sheet/Fragebogen + Logic-Check)
→ Rechnung → Nachbereitung.

## Ablage (wird bei Bedarf befüllt)

| Ordner | Inhalt |
|---|---|
| `vertraege/` | Erzeugte Verträge (Word-Quelle + PDF an Veranstalter). |
| `info_sheets/` | Info Sheets / Fragebögen pro Event. |

Alles leer — dein Hub legt hier ab, sobald der erste Vorgang läuft. Nichts geht
an einen Veranstalter ohne dein **OWNER-GATE**.
