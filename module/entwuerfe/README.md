# Entwürfe — vorbereitete Antwort-Mails (warten auf Dirks Freigabe)

Hier landen die vom Morgen-Briefing (und auf Zuruf) vorbereiteten **Antwort-
Entwürfe**. Jeder Entwurf ist eine fertige Mail — **nichts davon wurde gesendet**.
Versand nur nach explizitem OWNER-GATE-Ja über `scripts/send_email.py`.

## Ablage

- Body-Datei: `module/entwuerfe/<JJJJ-MM-TT>_<kurz-betreff>.html`
- Zusätzlich Ansicht-Kopie in `Ansicht Dokumente/hub_Owner/` (gleicher Name).
- Zu jedem Entwurf eine Kopfzeile im Briefing: Von-Postfach, An, Betreff, Absender
  (Dirk oder Helen Sanders), Bezug.

## Regeln (aus 00_core / 01_booking)

- **Absender-Frage:** Default = Dirk Wöhrle persönlich (konservativ). Nur Helen
  Sanders, wenn es klar eine Sekretariats-Formalie ist.
- **DU/SIE** aus dem bisherigen Verlauf spiegeln; unklar → SIE.
- **Keine** Gagen/Preise/Konditionen im Entwurf (→ Dirk übernimmt).
- Externe Mail = HTML + passende Firmen-Signatur (`module/signaturen/`).
- Nach Versand: Entwurf → `Ansicht Dokumente/hub_Owner/_archiv/`.
